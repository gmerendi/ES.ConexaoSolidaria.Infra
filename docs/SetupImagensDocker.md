# Setup de imagens Docker #

**Criar as imagens dos conteineres**<br>
  1. Clique com o botão esquerdo do mouse sobre a pasta "docker" e selecione a opção "Open in Terminal"<br>
   <img width="570" height="482" alt="image" src="https://github.com/user-attachments/assets/45b14c32-0d0a-43a3-9c2b-a9c3151e2333" /><br><br>

  2 Digite no powershell aberto o comando:
  ```bash
  docker-compose build
  ```
  3 Aguarde até que as imagens tenham sido criadas.<br>
